1-2. 이메일이나 다른 경로로 문의하실 때

고객이 직접 알려 주시는 범위 — 성함 또는 상호, 회신 받을 연락처, 문의 내용 — 만 남습니다. 문의 응대와 그 기록 외의 목적으로 쓰지 않습니다.

1-3. 파일 안에 들어 있는 개인정보

고객 파일에는 담당자 이름·전화번호·주소 같은 개인정보가 들어 있을 수 있습니다. 저희는 그 내용을 복원 작업 목적으로만 처리하며, 따로 뽑아내거나 저장하지 않고, 아래 4항의 파기 정책에 따라 지웁니다.

1-4. 결제 정보

현재 무료 베타 기간이라 요금을 받지 않으며, 결제 수단 정보를 일절 수집하지 않습니다. 카드번호·계좌번호를 입력받는 화면 자체가 없습니다. 유료 전환 시에는 이 문서를 먼저 갱신하고 시행일 전에 공지합니다.

이 사이트에 쓰인 모든 예시 이미지는 저희가 직접 만든 가상의 샘플입니다.

3. 파일이 지나가는 경로

어디를 거쳐 어디에 저장되는지 그대로 적습니다.

  1. 진단 단계 — 파일이 전송되지 않습니다. 복원 대상인지 확인하는 첫 단계는 고객의 브라우저 안에서만 실행됩니다. 이때 파일은 고객 컴퓨터를 벗어나지 않습니다.
  2. 복원 단계 — 이때부터 전송됩니다. 고객이 「복원 시작」을 직접 누르면 파일이 저희 서버로 전송됩니다.
  3. 복원은 국내에 있는 운영자 PC 에서 수행됩니다. 해외 클라우드에 올리지 않습니다.
  4. 외부 AI API 로 내보내지 않습니다 — 고객이 그 작업에 동의한 경우는 예외입니다. 기본값은 «전송하지 않음» 이며, 복원 계산은 전부 이 서버 안에서 이루어집니다. 아래 3-1 의 교차검증을 켜신 작업에서만 글자 줄 크롭 이미지가 밖으로 나갑니다. 지금 서버가 그 선택지를 제공하는지는 /api/health 의 vision 항목으로 확인하실 수 있습니다.

3-1. 외부 교차검증 (선택 — 켜지 않으면 아무것도 나가지 않습니다)

한글은 믈/물, 뮴/듐, 촤/화 처럼 모양이 비슷한 글자가 많아, 도형 대조만으로는 자주 갈리지 않습니다. 그래서 복원 화면에 「외부 교차검증 허용」 선택지를 두었습니다. 기본은 꺼져 있고, 고객이 그 작업에서 직접 체크하실 때만 켜집니다.

켜시면 개인정보가 국외로 이전됩니다 — 아래 내용을 확인하고 정해 주십시오

  • 동의는 그 작업 하나에만 적용됩니다. 다음 작업으로 이어지지 않으며, 매번 다시 정하실 수 있습니다.
  • 저희는 이전한 이미지를 저희 모델 학습에 사용하지 않습니다.
  • 작업이 끝나면 결과 화면과 검증 리포트에 실제로 외부 전송이 있었는지를 그대로 표시합니다. 나가지 않은 경우에도 «나가지 않았다» 고 적습니다.
  • 운영자가 이 선택지를 제공하지 않는 기간에는, 체크 여부와 무관하게 어떤 경우에도 전송되지 않습니다.
전송 구간에 관한 고지 — Cloudflare 저희 서버는 공인 IP 를 직접 열지 않고 Cloudflare Tunnel(Cloudflare, Inc., 미국)을 통해 외부와 연결됩니다. 따라서 고객이 업로드·다운로드하는 트래픽은 Cloudflare 의 네트워크를 경유합니다. 전 구간은 HTTPS 로 암호화되지만, 경유 사업자가 존재한다는 사실을 숨기지 않고 밝힙니다.

저장은 국내(운영자 PC)에서만 이루어지며 Cloudflare 는 파일을 보관하지 않습니다. 이 경로가 부담되시면 파일을 웹에 올리지 마시고 직접 문의해 주십시오 — 다른 전달 방법을 협의해 드립니다.

5. 제3자 제공과 위탁

5-1. 제3자 제공

개인정보를 제3자에게 제공하지 않습니다. 다만 (1) 고객이 미리 동의한 경우, (2) 법령에 규정이 있거나 수사기관이 법령에 정한 절차와 방법에 따라 요구하는 경우는 예외입니다.

5-2. 처리 위탁 현황

현재 실제로 쓰는 것만 적습니다. 늘거나 줄면 이 표를 먼저 고칩니다.

Anthropic 은 고객이 그 작업에 동의하지 않으면 어떤 데이터도 받지 않습니다. 동의 여부·이전 항목·거부 방법은 위 3-1 에 적었습니다.

웹사이트 페이지 자체는 GitHub Pages 에서 제공되지만, 고객 파일은 GitHub 에 올라가지 않습니다. 파일은 위 3항의 경로로만 전송됩니다.

마켓플레이스(크몽·숨고 등)나 결제대행사는 현재 사용하지 않습니다. 사용을 시작하면 이 표에 추가하고 시행일 전에 공지합니다.

6. 이용자의 권리

  1. 업로드한 파일과 결과물의 즉시 삭제를 요청하실 수 있습니다. 결과 화면의 「지금 서버에서 삭제」 버튼으로 직접 하실 수 있고, 문의로도 가능합니다.
  2. 처리 현황의 열람, 정정, 처리 정지를 요청하실 수 있습니다.
  3. 회원가입이 없으므로 별도의 탈퇴 절차는 없습니다. 파일을 삭제하면 저희에게 남는 것은 파일 내용이 없는 수치 로그뿐입니다.
  4. 개인정보 침해로 도움이 필요하시면 아래 기관에 문의하실 수 있습니다.
    • 개인정보 침해신고센터 (privacy.kisa.or.kr / 국번없이 118)
    • 개인정보 분쟁조정위원회 (kopico.go.kr / 1833-6972)
    • 대검찰청 사이버수사과 (spo.go.kr / 1301)
    • 경찰청 사이버수사국 (ecrm.police.go.kr / 182)

7. 안전조치

  1. 전송 구간 전체를 HTTPS 로 암호화합니다.
  2. 복원 서버는 외부에 직접 열려 있지 않습니다. 터널을 통해서만 닿습니다.
  3. 과도한 요청을 막는 접근 제한을 둡니다. 접속 IP 는 해시로 변환해서만 저장합니다.
  4. 작업 로그에 파일 내용을 기록하지 않습니다.
  5. 보관 기간이 지난 파일을 자동으로 지우는 절차가 15분마다 실행됩니다.
  6. 운영은 현재 1인 체제이며, 접근 권한을 가진 사람은 운영자 본인뿐입니다.

8. 쿠키·자동 수집

이 웹사이트는 쿠키를 사용하지 않습니다. 광고·분석 도구를 넣지 않았고, 방문자를 추적하지 않습니다. 브라우저 저장소도 쓰지 않습니다.

복원 서버는 접근 제한을 위해 접속 IP 를 해시로 변환한 값과 시각을 기록합니다. 원본 IP 는 저장하지 않습니다.
